# 邮箱账号与空间管理实施计划

**Goal:** 在本地完成邮箱注册验证、登录找回、多小组空间和小组资料设置。

**Architecture:** Supabase Auth 负责线上邮箱认证，本地提供带令牌和邮件预览的等效适配；应用签发全局账号会话，通过 account_id 解析目标空间成员，保留旧会话用于绑定。增量迁移不重建已有业务表。

**Tech Stack:** Next.js 16.3.5、React 19、Supabase Auth、PGlite PostgreSQL、Node scrypt、Vitest。

- [x] 账号基础：红绿测试、账号/会话/邮件令牌迁移、本地传输、密码摘要、验证/重置/重发/退出与旧身份绑定完成。
- [x] 小组服务：登录创建/加入、多空间列表/切换、创建者名称/头像设置、SSE 与重复加入身份复用完成。
- [x] 页面：邮箱登录注册验证与找回、我的空间、账号菜单和手机旧身份绑定入口、小组设置完成。
- [x] 集成：现有 API 按目标空间鉴权，聊天按会话所属空间鉴权；旧匿名数据继续保留，绑定后所有旧会话撤销；浏览器测试脚本加入邮箱验证前置。
- [x] 验证：25 文件 206 项测试通过；ESLint、类型检查与生产构建通过。独立本地数据库的实际 HTTP 验收涵盖两账号注册/验证、未验证登录拒绝、多空间与隔离、共享记录、创建者设置、密码找回/重放拒绝/旧会话撤销。浏览器视觉检查未执行，因为保存的访问权限拒绝；没有通过其他浏览器绕过。
