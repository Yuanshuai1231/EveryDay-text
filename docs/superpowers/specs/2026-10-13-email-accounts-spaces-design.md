# 邮箱账号与小组空间

2026-10-13 用户要求先在本地将入口改为用户注册/登录，登录后创建或加入空间，并为小组提供名称与头像修改。用户确认采用邮箱+密码，要求考虑线上邮箱验证。当前云端和 GitHub 不在本次修改范围内。

## 身份与数据

账号与小组成员身份分开。一个经过邮箱验证的账号可加入多个空间，清除浏览器或换设备后通过邮箱和密码恢复组内身份。现有 members、日志、聊天和角色保持不变；增量迁移为成员增加 account_id，并新增账号、全局账号会话和一次性验证/找回令牌表。业务表仍仅经服务端鉴权读取。

保留有效旧浏览器会话用于显式绑定已有空间；仅持有旧会话令牌的用户可绑定对应成员，不允许通过昵称或邀请码认领别人的历史。新创建和加入必须登录；同一账号重复加入同组返回原成员，不再新增身份。移除成员只失去该组权限，不退出其他组或整个账号；重新加入复用原成员及历史。

## 邮箱验证

线上 Supabase 模式使用 Supabase Auth 的邮箱注册、密码登录、验证邮件和重置邮件。服务端验证 Supabase 的返回身份后签发应用自己的 HttpOnly 账号会话，继续使用现有服务端成员鉴权。邮件回调采用 token_hash 与一次性验证入口，需要上线前配置 Supabase 邮件模板、Site URL、重定向 URL 和 SMTP。禁止默认服务端自动确认邮箱。

本地 PGlite 模式提供等效注册/验证/找回流程：密码以带随机盐的 scrypt 摘要存储，令牌仅存摘要、限时且只能用一次。测试邮件保存到本地预览收件箱；该入口仅允许本地模式、非生产环境、回环地址。邮件链接验证后登录；重置密码需邮件授权，并撤销已有账号会话。所有认证写入检查同源并限流，不暴露密码、会话原文或已注册邮箱信息。

## 页面

首页沿用现有插画和配色，右侧改为登录/注册，包含昵称、邮箱、密码、确认密码及忘记密码入口。验证邮件提示支持重发；登录后进入“我的空间”列表，可以创建、输入邀请码加入、切换及退出账号。个人头像仍可选择卡通动物。

小组侧栏和面包屑支持返回我的空间。小组设置页面仅创建者可编辑名称和动物头像，成员只读；头像和名字通过现有汇总/实时刷新同步到组内。旧用户在空间内获得绑定账号提示。

## 验证与范围

使用独立数据库测试注册、重复邮箱、未验证登录、验证令牌重放/过期、重置与撤销、跨账号空间隔离、重复加入、旧身份绑定和创建者设置权限。组件测试覆盖登录注册/邮箱提示、空间列表和设置。运行全量测试、lint、类型和生产构建。浏览器视觉 QA 若仍被保存的权限限制拦截需准确报告；此次不推送、不部署、不执行云迁移。
