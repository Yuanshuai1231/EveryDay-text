# 空间图标、日历与每日清单

本次修改先保存在本地，没有推送 GitHub 或修改云数据库。

空间头像使用独立物品图标目录，已有动物空间头像自动转换成物品图标；成员头像仍使用动物。概览、每日打卡、小组任务及任务编辑共用日期选择器。

## 清单使用

- 每日打卡点击“添加任务”，填写标题、备注、计划日期，选择“仅这一次”或“每天重复”。
- 每行圆形勾选表示该任务完成，再次点击可取消。成员只能编辑自己的条目，同组伙伴可以看到清单和完成状态。
- 一次任务未完成时会出现在之后的日期，保留原计划日期并用橙色标记“逾期未完成”。完成日仍显示完成记录，后续日期不再列出。
- 每天重复任务从起始日期开始，每天的勾选独立。停止重复从所选日期生效，之前的记录保留。重复系列的标题和备注编辑会同步到整个系列。
- 旧版上午/下午的已保存文本转换成一次任务，完整内容保存在备注里，原始日志仍保留。

每日记录为任务清单，不提供闹钟或推送提醒。

每日打卡只使用 `personal` 任务，由本人记录和完成；小组任务只使用 `group` 任务，在小组任务页选择一名组内成员创建。小组目标不会出现在每日打卡，也不会触发个人整日打卡。创建者可以编辑、停止重复或删除，负责人可以勾选完成；任务负责人创建后固定。

## 删除与退出空间

空间列表卡片和空间设置页均提供操作：创建者可删除空间，普通成员可退出。点击后会显示包含空间名称和影响范围的确认提示。

删除空间会清除该空间所有任务、打卡和聊天记录。退出保留历史记录，但不再允许访问或修改；账号登录和其他空间继续可用。创建者需先转交空间才能退出，不能直接丢下空间。

本次增加第三份增量迁移 `20261013000600_space_lifecycle.sql`，在前面两份之后执行。该迁移添加删除事务、完善退出后的会话选择清理，并处理空间删除时的循环外键、聊天发送者约束和任务级联保护。后续上线时应先执行此迁移，再发布带删除/退出按钮的代码。

随后执行 `20261013000700_legacy_task_completion_dates.sql`，为已应用旧版清单迁移的数据库修复原本没有计划日期的旧已完成任务，避免错误显示为逾期待办。原完成时间、成员和其他任务不会改写；已修复数据不会重复更新。
